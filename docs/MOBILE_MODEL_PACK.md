# Mobile model pack contract

Current Android contract: `mobile_i2v_v1`, format version **3**.

The authoritative specification is `docs/MODEL_PACK_SPEC.md`.

Core runtime files are:

- `vae_encoder.onnx`
- `mobilei2v_transformer.onnx`
- `video_decoder.onnx`
- `null_condition.bin`
- `null_attention_mask.bin`
- `runtime.json`
- `manifest.json`

The former `mobilei2v_unet.onnx` / `turbo_vaed.onnx` names are obsolete and
must not be used for new packs. MobileI2V's denoiser is MobileDiT, and the
Android contract names it `mobilei2v_transformer.onnx`.

Lite mode does not ship Qwen2. It uses a pinned empty-prompt embedding plus the
matching attention mask generated by `tools/generate_null_condition.py`.

The repository intentionally does not rename or bundle raw desktop checkpoints
as Android models. ONNX graphs must be converted and verified against the
official tensor contract before packaging.
